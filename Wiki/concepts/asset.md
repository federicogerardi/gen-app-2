# Asset

## Definition
An **Asset** represents a project-level resource or entity within a tool ecosystem. It serves a dual role in workflows, functioning both as an input source (as part of the project-asset family) and as a specific deliverable or output type generated by tools.

## Key Characteristics
- **Dual Role**: Functions as both an input material to drive tools and as a final deliverable produced by tool execution.
- **Project-Level Scope**: Serves as a fundamental resource across project workflows.
- **Specific Categorization**: Common classifications include specialized types such as 'brief', 'brand-voice', and 'persona'.
- **Ecosystem Integration**: Acts as a connective node between input requirements and output artifacts within a tool ecosystem.

## Applications
- **Input Source Configuration**: Used as foundational input data or context (e.g., project briefs or brand voice guidelines) to guide tool behavior and generation processes.
- **Output Deliverable Generation**: Created or output by specialized tools to serve as reusable deliverables for subsequent project stages.
