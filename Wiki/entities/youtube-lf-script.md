# youtube-lf-script

## Description
`youtube-lf-script` is a multi-step [[entities/tool|Tool]] designed for generating scripts for YouTube videos, particularly focusing on long-form content or lead funnels. Registered under the canonical ToolKey `youtube-lf-script`, it features a six-step workflow, making it one of the more complex tools in the application suite. Its workflow is composed of extraction and generation [[entities/workflow-step|WorkflowSteps]] that facilitate progressive context enrichment prior to creating a final [[entities/artifact|Artifact]]. It functions as part of a broader software suite alongside tools such as [[entities/geometric|geometric]] and [[entities/brief-generator|brief-generator]].
