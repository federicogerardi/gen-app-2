# 99-lifecycle — Archive & Lifecycle

Archived plans, superseded documents, and historical reference for the `gen-app-2` system.

## Structure

| Path | Purpose |
|---|---|
| [99-archive/plans/](./99-archive/plans/) | Completed and abandoned development plans |
| [99-archive/superseded/](./99-archive/superseded/) | Documents explicitly replaced by newer versions |

## Governance
Archived documents retain valid frontmatter for tooling but are frozen.
Superseded documents must include `superseded-by` field in frontmatter.
See [Documentation Governance](../07-governance/documentation-ddd-ul-governance.md) for lifecycle rules.
