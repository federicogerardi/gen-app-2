# Domain Ubiquitous Language Glossary

## Scope
- Canonical domain vocabulary for the current workspace (`gen-app-2`).
- Source of truth for domain terms used across analysis, development, testing, operations, and user documentation.
- Bounded contexts covered: **Generation**, **Auth**, **Usage/Quota**, **Frontend/UI**.

## Cross-Context Concepts

| Term | Type | Definition | Source | Status |
| --- | --- | --- | --- | --- |
| Tool | Concept | A system instrument that encapsulates a complete user-facing capability: it accepts structured user input (e.g., a `BriefingFile` upload or typed form fields), executes an ordered chain of `WorkflowStep`s that progressively enrich context at each pass, and produces one or more `Artifact`s as final output.
